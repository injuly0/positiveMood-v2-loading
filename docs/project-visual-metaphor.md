# 完整整理｜全页面外观、动效思路与视觉隐喻
产品内核：积极心理学，核心概念 **Savoring（品味积极记忆、二次深度思考）**
统一视觉叙事主线：**私人信件博物馆**

## 一、各页面动效方案汇总
### 1. 初始页（首页）
#### **双空间入口结构（推荐落地）**
底层逻辑：**书写记录、回味品味同等重要**，回味的三种模式属于展厅内部分支，不前置摊开。
- 右侧空间：书写书桌区域 → 对应【记录】
- 左侧空间：拱形展览厅门洞 → 对应【回味合集】
  用户选择展厅区域时，墙上的文字变成三种子菜单的选择。再选择三种模式：时间线陈列 / 精选回味 / 随机品味。

##### 视觉场景与动效设想
首页为一间安静小房间平视/鸟瞰场景；
书桌与拱门两大区域视觉重量均等，不用标准化按钮，依靠**空间叙事引导选择**；
拱门深处虚化、薄雾效果，隐约透出展架信件微光，暗示里面存放过往记忆。
- 点击右侧书桌：镜头平缓推向金属托盘，信纸缓缓浮现，平滑过渡至记录页
- 点击右侧拱门：镜头向门洞内纵深推进，淡入展厅导览面板，选择三种回味模式

### 2. 记录页｜金属托盘信纸：折叠→展开交互
核心方案：**原地展开，不新开页面跳转**
1. 点击托盘上的信件：信纸周围出现光晕，信纸的边缘高亮；金属托盘、背景同步虚化后退(进阶)
2. 信纸完全展开后，输入光标缓缓显现
3. 默认浅灰色仿手写占位文案：「亲爱的自己：」，用户输入文字覆盖其上
优势：维持情绪连续性，用户感知始终处在**同一张信纸**内，割裂感弱。

### 3. 问题选择页｜原始记录 VS AI待选问题排版叙事
层级关系：原始记录作为背景，待选问题作为主体
1. 用户刚写完的记录信纸缩小，放置页面上方/左侧，充当引用背景
2. 多份待选问题信封从画面侧边飘入，扇形堆叠展开（类似塔罗牌排布）
3. 选中其中一张信封，其余信封平滑虚化退场，进入回答页
叙事隐喻：你寄出一封信，收到多封回信，挑选其一深入对话。

### 4. 问题回答页【核心模糊页，优先敲定】
摒弃三块内容独立模块堆砌；统一载体：**同一张信纸**
视觉结构——信纸左右翻开的双面形态：
- 左上区域：小字引用原始记忆（信件背景）
- 中间区域：斜体/引用样式展示AI深思问题（来信正文）
- 右侧/下半区：空白书写区域，供用户作答
隐喻：一侧是向你提出的疑问，一侧是你的内心回应，合并构成完整信件，贯穿全产品「信件承载深度思考」主线。

### 5. 存储展示·时间线页面｜信件展架排布
1. 载体：多层木质陈列架
2. 排序规则：时间有序（从左至右、从上至下；最新信件放置视觉最优位置）
3. 信件尺寸统一；**不依靠大小区分重要程度**（重要性区分交给精选回味页）
4. 滚动交互：**横向滚动**
体感模拟：缓步走过陈列长廊；纵向滚动容易变成信息流刷Feed，削弱博物馆叙事。

### 6. 精选回味页｜打造隆重仪式感
避免大面积装饰元素泛滥导致视觉疲劳
- 少量高价值信件（3–5封）：独立圆形聚光展台、局部光影烘托，如同博物馆镇馆之宝
- 其余信件缩小，作为周边辅助展品陈列
层级区分：核心展品+次级展品，营造重点记忆的专属隆重感。

### 7. 随机品味页｜散落信件交互
1. 信件自然散落在台面，摆放角度随机，搭配柔和投影
2. 划动经过：信件轻微晃动，模拟微风拂动
3. **长按停留触发完整展开**，单击仅轻微悬浮预览
低压力随机邂逅记忆，契合随性品味的体验。
