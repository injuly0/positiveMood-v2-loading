# Project instructions

Before substantial feature work or code generation, read `docs/README.md`, then read the task-relevant documents listed there.

Before generating or modifying code related to routing, static assets, Vite configuration, build output, or deployment, read and follow `docs/deployment-path-convention.md`.

The application is mounted at `/letter/`. Do not change this convention or hardcode conflicting root-relative resource URLs unless the user explicitly requests a deployment architecture change.

When adding, deleting, renaming, or changing the responsibility or status of a document under `docs/`, update `docs/README.md` in the same change.
